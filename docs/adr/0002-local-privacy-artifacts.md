# ADR-0002: Приватность и артефакты локального прогона

- Статус: accepted
- Дата: 2026-10-31

## Контекст

Книга легально приобретена, но её текст нельзя публиковать. При этом системе
нужны исходный PDF, извлечённый текст, индексы, эмбеддинги, трейсы и audit.
Нужно однозначно разделить tracked-контент и локальные артефакты, чтобы
случайный `git add` не утёк данные.

## Классификация данных

| Класс | Примеры | Путь | Git |
| --- | --- | --- | --- |
| Исходник | реальный PDF | `data/raw/` | запрещён |
| Производные | extracted text, OCR, chunks | `data/processed/` | запрещён |
| Индексы и состояние | Qdrant volume, SQLite catalog, FTS5 | `data/artifacts/` | запрещён |
| Локальные отчёты | manifest, eval report, трейсы, audit | `data/artifacts/`, `*.local.json` | запрещён |
| Synthetic fixtures | ручной текст без книги | `tests/fixtures/`, `data/eval/*.example.json` | разрешён |
| Конфигурация | `.env`, ключи API | `.env` | запрещён |

## Правила

1. В tracked-файлах запрещены: source/extracted/OCR text, цитаты, passage и
   chunk text, реальные page labels, названия/авторы книги, абсолютные пути.
2. Реальные PDF и производные артефакты не покидают машину: никаких облачных
   embeddings/LLM по умолчанию. Облачный провайдер — только явное opt-in через
   `.env` с предупреждением в `doctor`.
3. Локальные отчёты именуются `*.local.json`; примеры и шаблоны —
   `*.local.example.json` и остаются tracked.
4. Трейсы и audit не содержат текста книги: только id, длины, scores, имена
   инструментов и усечённые безопасные поля. Текст фрагментов пишется только
   при `BOOK_EXPERT_TRACE_TEXT=1` и остаётся в git-ignored пути.
5. SQLite-каталог хранит абсолютный путь к PDF только локально и никогда не
   попадает в отчёты/коммиты.
6. Удаление книги — это удаление записей Qdrant/FTS5/каталога и производных
   файлов; исходный PDF удаляет пользователь вручную.

## Последствия

- Проверка утечек: `git status --ignored`, `git check-ignore -v <path>`,
  pre-commit `check-added-large-files`.
- Любой новый артефакт сначала получает правило игнора и только потом
  создаётся кодом.
- При добавлении облачного провайдера требуется отдельный ADR и явное
  согласие пользователя на отправку фрагментов книги.
