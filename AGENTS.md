# AGENTS.md

Контракт для coding agents, работающих в этом репозитории.

## Scope
- Перед началом работы пойми цель задачи и подтверди её объём (scope) с пользователем.
- Не изменяй архитектуру проекта, зависимости, lockfile (uv.lock) или файлы вне задачи без явного согласования.
- Репозиторий намеренно минимален: не делай ненужный рефакторинг и не расширяй границы задачи.

## Запрещено
- Добавлять или обрабатывать реальный PDF, извлечённый текст, embeddings, индексы, secrets или traces.
- Коммитить .env, содержимое data/raw, data/processed, data/artifacts и другие приватные артефакты.
- Выполнять git add/commit/push/reset/clean без явной просьбы пользователя.

## Проверки перед завершением
Запусти и убедись в успешном завершении:
- uv sync
- uv run ruff format --check .
- uv run ruff check .
- uv run pytest
- uv run pre-commit run --all-files

## Финальный отчёт
Укажи: изменённые файлы, выполненные команды, результаты проверок и непроверенные ограничения.
