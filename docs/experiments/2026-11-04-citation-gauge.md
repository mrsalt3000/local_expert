# Citation gauge: используются ли цитаты на самом деле, 2026-11-04 (T85)

Гипотеза: page-overlap `citation_precision` ≈ 1/N занижает качество цитат,
потому что измеряет разбавленность списка, а не корректность. Проверка —
новая метрика на уровне отдельной цитаты.

**Итог: гипотеза подтверждена.** Все 5 цитат «Агента» используются в
утверждениях, 94% поддерживают хотя бы одно утверждение. Фильтровать цитаты
нечего — надо менять отчётность, а не продукт.

## Что добавлено

`FaithfulnessReport` и судья считают по каждой цитате ответа:

- `citations_available` — сколько цитат показано пользователю;
- `citations_referenced` — сколько из них упомянуты маркером `[n]` хотя бы в
  одном утверждении;
- `citations_supporting` — сколько из упомянутых поддерживают хотя бы одно
  утверждение (`supported_by_cited`);
- `citation_usage` = `referenced / available` — доля цитат, которые вообще
  используются;
- `citation_support_rate` = `supporting / referenced` — доля использованных
  цитат, которые реально подтверждают утверждение.

Знаменатель — число цитат ответа (`citation_count`), а не число фрагментов
контекста: иначе метрика штрафовала бы за сам факт показа 20 фрагментов.

## Результат: «Агент», 20 кейсов

Прод-конфигурация: deepseek-ответы, судья `ollama/qwen3.5:4b`, cap 5 цитат,
scope 3, k=20. Прогон — `data/artifacts/t85-agent-citations.local.json`.

| Метрика | Значение |
| --- | --- |
| page-overlap `citation_precision` | **.1775** |
| `citation_book_precision` | .8600 |
| `citation_usage` | **1.0000** |
| `citation_support_rate` | **.9368** |
| `citation_support_precision` | .7737 |
| `faithfulness` | .8822 |

Распределение по 19 оценённым ответам:

- `citation_usage = 1.0` во **всех 19** — ни одной «декоративной» цитаты;
- `citation_support_rate`: медиана **1.0**, минимум .6, ниже 1.0 у **5 из 19**;
- у **4** ответов page-overlap precision = 0, и у всех четырёх
  `citation_support_rate ≥ .8`: они цитируют валидные страницы, просто не
  размеченную золотую.

То есть `.1775` — арифметика `1/5`, а не «плохие цитаты». Ответы опираются на
все пять страниц, и почти каждая из них что-то подтверждает.

## Решение

- Продукт не меняем: фильтровать нечего, все цитаты используются.
- В отчётах `stage-eval`/`agent-eval` теперь есть `citation_usage` и
  `citation_support_rate` (per-case и в среднем).
- Для решений о цитатах смотреть на `citation_support_rate`, `citation_recall`
  и claim-level support; page-overlap precision держать как sanity-check или
  убрать из заголовков.
- Дефолты и промпты не менялись.

## Ограничения

- 20 кейсов, один прогон; судья локальный 4B, консервативный (T74: FN 7.9%,
  FP 0%).
- `citation_usage` ограничен сверху единицей; если ответ цитирует одну
  страницу дважды разными маркерами, это считается одной цитатой.
- Метрика не проверяет, что цитата подтверждает **именно тот** факт, ради
  которого стоит маркер: для этого нужен claim→citation entailment.
